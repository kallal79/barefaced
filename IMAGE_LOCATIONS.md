• 🛡️ Tactical Lifelines: Truth Shield protection, Bluff Traps, 50/50 Lie Radar, and Double Down wagers.
• ⏱️ Custom Match Lengths: Quick Sprint (1 Round), Standard Show (3 Rounds), Marathon (5 Rounds), and Infinity Survival Mode.
• 🏆 3D Olympic Podium: Dynamic titles ("Master Bamboozler", "Eagle-Eye Detective") and awards for the best lies.

🛠️ TECH STACK:
• React 18 • TypeScript • Vite • Tactile Editorial CSS
• Netlify Functions + @netlify/blobs with ETag optimistic concurrency (no lost updates)
• Client-side dual-engine fallback (zero server errors, runs offline & cross-tab via BroadcastChannel)
